# Креативный музей — локальное приложение и пакет задания

Версия 1.0 · 20 октября 2026 · выбран дизайн 01 «Чистый диалог».

В репозитории теперь есть запускаемая локальная реализация: React/Vite в `apps/web`, FastAPI и SQLAlchemy в `apps/api`, миграции в `db/migrations`. Исходное ТЗ сохранено без изменения: `SPEC.md` и отдельные документы раскрывают дизайн, данные, API и приемку.

## Быстрый запуск

Откройте `creative-museum.code-workspace` в Visual Studio Code и запустите задачу `Dev: всё приложение`. Интерфейс будет доступен на <http://127.0.0.1:5173>, API — на <http://127.0.0.1:8000/docs>. Подробности находятся в `LOCAL_DEVELOPMENT.md`.

Локальный demo-вход администратора: `admin` / `konkursadmin`. Этот пароль запрещён для production. Без `OPENAI_API_KEY` ответы строятся локальным поиском по импортированной базе и помечаются как demo; серверная интеграция Responses API включается конфигурацией.

## Что зафиксировано заказчиком

Русскоязычный сайт поддержки конкурса, ответы через GPT только по теме и базе, зеленый маскот с эмоциями, публичный FAQ, вход в админ-панель через иконку справа сверху, просмотр и выгрузка сообщений, вкладка расходов и редактор FAQ. Выбран конкретный референс из приложенного изображения.

В `knowledge/qa_source.txt` лежит приоритетная база готовых вопросов и ответов, а в `knowledge/general_source.txt` — второй уровень общих материалов. В `knowledge/source_manifest.json` зафиксированы роли, размеры и контрольные суммы. Текст ответа при отсутствии данных редактируется в разделе «База знаний» админ-панели.

## Порядок приоритета

1. Явные последующие указания заказчика.
2. `SPEC.md` и `docs/DECISIONS.md`.
3. Детальные документы дизайна, API и данных.
4. Референс как визуальная цель; все функции определяет текст ТЗ.

Вопросы о правдивости правил конкурса разрешает редактор оператора. Изображение и тестовые примеры не являются нормативными источниками. Даты и условия из исходной базы нельзя автоматически переносить на новый сезон.

## Состав

`START_HERE.md` — стартовое задание; `SPEC.md` — продукт; `design/` — выбранный образ и токены; `docs/` — архитектура, контракты и приемка; `knowledge/` — исходная база и правила обработки; `config/.env.example` — перечень настроек без секретов; `MANIFEST.sha256` — контрольные суммы комплекта.

Неуточненные параметры имеют явно обозначенные рабочие значения. Их можно менять конфигурацией без переделки приложения. Это не означает, что заказчик уже утвердил сроки хранения, нагрузку или стоимость инфраструктуры.
