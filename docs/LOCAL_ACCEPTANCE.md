# Локальная приёмка

Дата: 20 октября 2026. Профиль: macOS, локальная SQLite, `DEMO_MODE=true`, без `OPENAI_API_KEY`.

## PASS

- ZIP проверен по `MANIFEST.sha256`.
- Frontend собирается командой `npm run build`; TypeScript и Vite проходят без ошибок.
- `npm run lint` проходит без предупреждений.
- Backend: `3 passed` в pytest.
- Миграция Alembic `0001_initial` находится в `head`.
- База знаний импортирована: 111 записей; опубликованная версия проходит `kb validate`.
- Анонимная cookie-сессия и принадлежность диалога работают.
- Вопрос сохраняется один раз, request завершается, ответ и source ID появляются в истории.
- Поиск возвращает полный раздел «Кто может участвовать», а сезон 2025–2026 явно помечается как legacy.
- Публичный FAQ читается без вызова модели.
- Локальный вход `admin / konkursadmin`, серверная admin-cookie и CSRF работают.
- Вкладки «Диалоги», «Расход токенов» и «Частые вопросы» получают данные из БД.
- FAQ поддерживает draft, правку с revision, публикацию, скрытие и изменение порядка.
- CSV/JSON-экспорт создаёт фиксированный snapshot и доступен только с admin-cookie.
- Интерфейс проверен в живом браузере: пустой чат, ответ, источник, вход и три административных раздела.

## NOT RUN / блокеры публичного запуска

- Реальный Responses API: ключ в окружении отсутствует. Код использует structured output, но оплачиваемый вызов не выполнялся.
- PostgreSQL/pgvector: профиль и Docker Compose подготовлены, Docker на текущем компьютере не установлен.
- Нагрузочные проверки 100 одновременных сессий, 10 генераций и экспорт 100 000 сообщений не выполнялись.
- Контрольный GPT-набор из 120 сценариев не утверждён и не запускался.
- Активный сезон, юридические тексты и production-пароль не утверждены.
- ImageGen подготовил концепт шести состояний в `assets/mascot/mascot-states-concept.png`, но прозрачный production-спрайт не получен; в приложении остаётся адаптивный CSS-маскот с шестью состояниями.
